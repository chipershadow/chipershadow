### Security Research & Methodology
My approach to security auditing prioritizes:
1. **Threat Modeling**: Mapping out trust boundaries, external dependencies, and privileged roles before reading code.
2. **Invariant Testing**: Identifying critical protocol invariants that must hold under arbitrary execution states.
3. **Static & Dynamic Analysis**: Combining manual code review with AST-based rule evaluation and fuzz testing.
4. **Reproducible Proof-of-Concepts (PoCs)**: Documenting findings with deterministic reproduction scripts without deploying to public testnets until verified.
